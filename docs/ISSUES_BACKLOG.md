# Starter issues

The starter issues (with labels and acceptance criteria) are created for you by:

```bash
./scripts/setup-github.sh YOUR-ORG/dev-passport
```

See [GITHUB_SETUP.md](GITHUB_SETUP.md). To change them, edit the `issue ...` lines in `scripts/setup-github.sh`.

Current starter list: light theme · accessibility audit · print/PDF layout · "earning stamps" guide · social-image helper tests ·
component tests · Playwright smoke tests · sort/filter stamps · Arabic translation (RTL) · shared rate limiter ·
embeddable badge · endorsements · recruiter view · self-hosting guide.
